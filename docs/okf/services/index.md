# Services & integrations

Synkage is a local process; no internal services. External integrations:
- [WhatsApp Web](whatsapp-web.md) — drafts + sends after confirmation (mock-tested)
- [Gmail](gmail.md) — drafts only (mock-tested)
- [Apple Notes](apple-notes.md) — macOS notes via osascript
- [OpenClaw runtime](openclaw-runtime.md) — optional execution substrate (planned).
